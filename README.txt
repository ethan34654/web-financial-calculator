# Basic Financial Calculator Project

An AI-assisted financial calculator project built with HTML, CSS, and JavaScript, featuring 10 interactive calculators for common personal finance and business calculations. AI tools were used to support development and debugging, while the project implements the calculation logic, input validation, and dynamic result displays in JavaScript.

**Files**
- `index.html`: Homepage with links to all ten calculators.
- `calculator.html`: Shared calculator form and results page.
- `calculator.js`: JavaScript logic for all ten calculators, including financial formulas, input validation, and result formatting.

**How to Run**
1. Extract the ZIP file.
2. Keep all three files in the same folder.
3. Double-click `index.html` or open it in your browser.
4. Choose a calculator, enter values, and click **Calculate Results**.

**Technical Features**
- Reusable calculator structure to support multiple financial tools through a shared interface.
- JavaScript-based calculations and input validation.
- Dynamic result displays with formatted currency and percentage values.
- Financial calculations covering loans, compound interest, retirement savings, budgeting, currency conversion, debt repayment, taxes, net worth, savings goals, and break-even analysis.

**Limitations**

No backend server is required; calculations run directly in the browser. The currency converter requires a manually entered exchange rate, while the tax estimator uses a simplified effective tax rate rather than jurisdiction-specific tax brackets.

*For educational purposes only. Results are estimates, not financial advice.*
